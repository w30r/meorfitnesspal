# Technology Stack

## Core Framework
- **Next.js 16** — React framework with App Router, Server Actions, and SSR/SSG support
- **React 19** — UI library with server components and concurrent features
- **TypeScript** — Type safety and developer experience

## Styling & UI
- **Tailwind CSS v4** — Utility-first CSS framework with PostCSS configuration
- **HeroUI** — Component library for React (Next.js-optimized)
- **shadcn/ui (radix-vega)** — Customizable component primitives built on Radix UI
- **class-variance-authority** — Component variant management
- **tailwind-merge** — Intelligent Tailwind class merging
- **tw-animate-css** — Tailwind animation utilities

## State Management
- **zustand** — Lightweight global state management

## Data & Database
- **MongoDB** — NoSQL database (native MongoDB driver v7)
- **Collections:** `foodlog`, `weightlog`, `goal`, `favoritefoods`

## Authentication
- **better-auth** — Cookie-based session authentication
- **Middleware:** Route protection for authenticated pages

## AI
- **Gemini 2.5 Flash Lite API** — Nutrition data parsing from meal descriptions

## Visualization
- **Recharts** — Composable chart library for React

## Icons
- **lucide-react** — Consistent icon set
- **react-icons** — Additional icon library

## Utilities
- **date-fns** — Date manipulation and formatting
- **motion** — Animation library for React
- **clsx** — Conditional class name construction

## Development Tools
- **ESLint** — Code linting
- **Turbopack** — Next.js development bundler
